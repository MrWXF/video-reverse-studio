# 前端重设计：电影级创作工作台

> 日期：2026-11-23<br>
> 状态：已实现并验证

## 1. 目标

这次重构不只替换颜色，而是重新整理工作台的信息层级和操作节奏：

- 让“上传/输入”成为页面主任务，而不是普通表单。
- 让项目库、任务状态和结果详情形成清晰的三段关系。
- 用统一的卡片、按钮、状态和间距建立完整设计系统。
- 保留现有 API、DOM 交互入口和零构建前端架构。

## 2. 视觉方向

采用“电影制作控制台”而非通用 SaaS 后台的方向：

- 暖黑背景，降低纯黑带来的生硬感。
- 琥珀橙作为唯一主强调色，承担操作、进度和焦点反馈。
- 大字号编辑式标题，搭配等宽字体处理编号、时间和技术元数据。
- 低对比细边框、局部径向光晕和网格底纹形成空间层次。
- 卡片使用较大圆角和轻微内高光，避免传统后台的方块堆叠感。

## 3. 设计变量

| 类型 | 变量 | 用途 |
|------|------|------|
| 背景 | `--bg`, `--bg-soft` | 页面与深色层级 |
| 面板 | `--panel`, `--panel-raised` | 卡片、侧栏、输入区域 |
| 文字 | `--text`, `--text-soft`, `--muted` | 标题、正文与辅助信息 |
| 强调 | `--accent`, `--accent-strong` | 主按钮、进度、选中态 |
| 状态 | `--success`, `--warning`, `--danger` | 完成、提醒、失败 |
| 圆角 | `--radius-xl`, `--radius-lg`, `--radius-md` | 24 / 18 / 12px 层级 |
| 字体 | `--display`, `--font`, `--mono` | 标题、正文、技术元数据 |

## 4. 页面结构

### 顶栏

- 左侧品牌区：图形标识、产品名和产品类别。
- 中央模式切换：逆向视频 / 生成提示词，支持键盘焦点和 ARIA 选中状态。
- 右侧运行模式与 API 文档入口。

### 逆向视频

1. 大标题说明能力，右侧展示分析维度、镜头上限和导出格式。
2. 上传卡片与新建项目卡片并排，上传区域成为视觉中心。
3. 下方项目库与详情区形成主工作区。
4. 详情区展示状态、分辨率、时长、帧率和操作按钮。
5. 分析完成前不再显示下载按钮，避免无效操作。

### 生成提示词

1. 使用独立标题和 01 Brief / 02 Storyboard / 03 Export 流程提示。
2. 表单分为创意输入区和参数设置区。
3. 结果页首屏展示方案摘要和四格指标。
4. 逐镜卡片展示景别、运镜、动作、场景、光线、转场、色板、Prompt、负向词和复刻笔记。

## 5. 组件规范

- 主按钮：琥珀渐变、深色文字、悬停上浮和箭头位移。
- 次级按钮：透明底、细边框，低视觉权重。
- 危险按钮：低饱和红色底，避免与主操作竞争。
- 状态徽标：完成、运行、排队和失败使用统一圆点 + 文本组合。
- 进度条：细轨道、渐变填充和微弱光晕。
- 项目列表：选中态使用左侧强调线和低饱和琥珀背景。
- 空状态：图标、标题和操作提示三段式，不再只显示一行灰字。
- Toast：固定右下角、玻璃背景、左侧强调线。

## 6. 响应式

- `1180px`：缩小侧栏和表单设置区。
- `980px`：模式切换占满第二行，侧栏移动到内容上方，详情改为单列。
- `720px`：压缩顶栏信息，标题和页边距缩小，表单改为单列。
- `520px`：项目列表、分镜卡和指标卡改为单列或两列，按钮占满可用宽度。
- 支持 `prefers-reduced-motion`，关闭非必要动画。

## 7. 重构范围

- `app/templates/index.html`：重建页面语义结构、标题、表单分组和空状态。
- `app/static/style.css`：重建设计变量、布局、组件和响应式规则。
- `app/static/app.js`：同步项目计数、状态属性、上传按钮忙碌态和完成态下载逻辑。
- `app/static/prompt.js`：同步模式 ARIA、任务计数、状态徽标、方案概览和逐镜卡片渲染。

后端 API、数据结构和认证逻辑保持不变。
