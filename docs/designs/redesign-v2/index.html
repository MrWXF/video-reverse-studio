FRONTEND REDESIGN / REVIEW SHEET

少一点操作，
多一点创作。

这次重做不换一张更花的皮，而是把「上传、看结果、生成提示词」重新收成一条清晰路径。首屏只保留一个主行动，复杂信息进入项目后再展开。

3步完成主流程
1个首屏主 CTA
4个核心界面

设计原则：一屏一个主动作；先给结论，再看细节；所有高频操作保持在原地完成。

01 / CORE SCREENS

三屏主路径

首页负责开始，项目页负责理解，提示词页负责交付。三段之间不再让用户在侧栏、卡片和弹窗之间来回找。

01

工作台首页 · 只做一件事

上传区占满主卡片，最近项目退到右侧；去掉四张统计卡，把“开始分析”变成唯一视觉焦点。

单一主 CTA最近项目三步入职
02

项目工作台 · 先看结论

视频、镜头时间轴和 AI 摘要同屏；选中镜头后在原位展开细节，不再把 24 个镜头一次性铺满页面。

同屏对照镜头选择结论优先
03

提示词工作室 · 一次填写，一次生成

创意描述、模板、镜头数和时长收在一张表里；右侧固定显示本次方案摘要与开始按钮，避免填完表单还要回头找操作。

三步进度右侧摘要生成前可确认结果可预览

02 / MOBILE FIRST

手机上也能完成主流程

移动端不是把桌面版缩小。主行动固定在同一视觉层级，底部导航只保留四个高频入口。

RESPONSIVE RULES

一只手，也能开始分析。

触控目标不小于 44px；上传、开始分析和移动导航都放在拇指容易够到的区域。表单在窄屏改为纵向堆叠，不出现横向滚动。

01
主按钮全宽“开始分析”在移动端占满卡片宽度，避免点不中。
02
底部四入口工作台、项目、提示词、质量，减少侧栏和抽屉。
03

04 / DESIGN SYSTEM

一套更克制的视觉语言

暖白画布降低长时间使用的疲劳，珊瑚橙只负责“下一步”，墨黑负责文字和结构，不再使用大面积紫色渐变。

PALETTE

Warm neutral + signal orange

  • Canvas#F2EEE6
  • Ink#1B1A16
  • Signal#FF5A36

TYPE

Display / UI / Mono

可拍的
分镜。

标题用系统无衬线，收紧字距；数据用等宽字体，帮助用户快速扫描。

INTERACTION

短、稳、可预期

  • 按钮反馈160–200ms
  • 卡片圆角18–22px
  • 触控目标≥ 44px
  • 焦点样式2–3px
  • 减弱动画支持
