# ReelReverse 前端设计方案

这一目录存放视觉设计稿与主题源文件。当前已选定方案 A「光屿 Studio」与方案 B「霓虹影棚」，生产前端已按两套方案重构，并支持在页面右上角实时切换、用 `localStorage` 记住选择。方案 C「日落片场」保留为后续视觉探索稿。

## 预览入口

在项目根目录运行：

```powershell
python -m http.server 8090 --directory docs/designs
```

然后打开：

- 设计总览：`http://127.0.0.1:8090/`
- 方案 A 光屿 Studio：`http://127.0.0.1:8090/design-a.html`
- 方案 B 霓虹影棚：`http://127.0.0.1:8090/design-b.html`
- 方案 C 日落片场：`http://127.0.0.1:8090/design-c.html`

也可以直接双击 `docs/designs/index.html`，设计和交互都能离线运行。

## 三套方案

### A · 光屿 Studio

- 定位：轻盈、清透、年轻的高品质 SaaS 工作台。
- 色彩：珍珠白、雾紫、珊瑚粉、海盐蓝、薄荷绿。
- 材质：玻璃卡片、柔阴影、大圆角、明亮渐变。
- 适合：消费品牌、社媒内容团队、第一次接触 AI 创意工具的客户。
- 优势：客户接受面最广，信息密度舒适，长时间使用不累。

### B · 霓虹影棚

- 定位：先锋、未来、强视觉冲击的 AI 创作影棚。
- 色彩：午夜蓝、电光青、洋红、柠檬黄、荧光绿。
- 材质：深色玻璃、霓虹细线、高对比光晕。
- 适合：AI 视频产品、创意热店、发布会与公开演示。
- 优势：第一眼记忆点最强，适合强调“AI 原生”和视觉能力。

### C · 日落片场

- 定位：电影感、编辑感、带制作公司审美的创意工作台。
- 色彩：暖象牙白、焦橙、珊瑚、海盐青、玫瑰粉、宝蓝。
- 材质：纸张肌理、硬投影、小圆角、编辑式衬线标题。
- 适合：广告片、品牌 TVC、影视制作与电商大片团队。
- 优势：品牌客户最容易感知“专业”和“审美”，适合高客单场景。

## 每套页面包含

- 顶部品牌、模式切换、AI 在线状态与主 CTA。
- 逆向视频：Hero、能力数据、上传/新建项目、最近项目、分析摘要、四个镜头卡片。
- 提示词生成：创意 Brief、参数面板、方案概览、四个分镜、Prompt / Negative Prompt、参数说明与导出区。
- 可交互演示：模式切换、项目切换、镜头展开/收起、Prompt 复制、生成中状态、Toast 提示。
- 响应式：桌面、平板和手机布局。
- 无外部图片、远程字体或 CDN，离线打开也不会丢样式。

## 设计文件


## 当前上线状态

- 生产页面默认使用方案 A；点击右上角「光屿 / 霓虹」可在 A、B 之间切换。
- 使用 `/?style=b` 可直接以霓虹影棚主题打开，便于演示与截图。
- 主题选择会写入 `localStorage`，刷新后继续沿用。
- 方案 C 不作为当前生产主题，只保留设计参考。
