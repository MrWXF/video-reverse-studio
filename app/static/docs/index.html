快速开始

一分钟跑通核心流程

STEP 01上传并分析POST /api/projects 上传视频，返回 project_id 与 job_id。
STEP 02订阅进度GET /api/jobs/{id}/events SSE 实时推送，完成即拿到分镜。
STEP 03生成提示词POST /api/prompt-projects 用创意简报生成逐镜配方。

认证

默认部署（未配置 APP_PASSWORD）所有接口免登录。配置密码后，除 /healthz 与分享链路外，业务接口均要求 HTTP Basic 认证：

SHELL
curl -u admin:你的密码 http://127.0.0.1:8000/api/projects
双入口说明：/api/* 为兼容入口，/api/v1/* 为正式版本入口，两者共享同一套 v1 语义，可任选其一。

通用约定

  • 长任务（分析 / 提示词 / 生成）均为异步队列模型：创建接口立即返回，随后通过任务接口或 SSE 轮询 / 订阅进度。
  • SSE 事件流：Content-Type: text/event-stream，data: 载荷为 JSON，包含 status、step、progress 等字段。
  • 错误统一为 {"detail": "中文错误说明", "request_id": "…"}；并发达到上限返回 503，稍后重试即可。
  • 上传上限由 MAX_UPLOAD_MB 控制（默认 512MB），超限返回 413。
没有匹配的接口换个关键词试试，比如 project、prompt、share。
